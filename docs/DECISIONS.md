## M5-A.1 Nearby Contract Lock Decisions (2026-10-08)
51. **Radius escalation locked rule:** Strictly execute: `evaluate <= 1km (if >=3 -> radius=1); else evaluate <= 3km (if >=3 -> radius=3); else evaluate <= 5km (radius=5); return at most 3 actual places`. Example: if 1km=1, 3km=2, 5km=2 -> final radiusKm=5, results=2. Never stop early at 3 km with < 3 results.
52. **Candidate retrieval contract:** Nearby mode must NEVER pre-filter Top 3 using old city-wide ranking before distance computation. M5-B repository must retrieve all eligible candidates for the active section + tag filter before computing distances, expanding radius, and ranking nearby. Non-location queries retain existing city-wide discovery/ranking (LIMIT 3).
53. **Distance precision contract:** Haversine calculation must maintain full floating-point precision for radius boundary filtering (`distanceRawKm <= 1.0`, `<= 3.0`, `<= 5.0`), sorting (`distanceRawKm ASC`), and deterministic selection. Never round before filtering or sorting (e.g. raw 1.04 km is not rounded to 1.0 km). Only final selected 0–3 places format `distanceKm` to 1 decimal place for UI display.
54. **GPS accuracy threshold:** Inspect `coords.accuracy`. If `accuracy <= 1000m`, proceed with Nearby. If `accuracy > 1000m`, do NOT send location to Nearby; display user message that position is not accurate enough; fallback to all Da Nang discovery; provide Retry action. Never fake location, never persist accuracy or location.
55. **Privacy contract:** M5-B continues using optional `lat`/`lng` query parameters over HTTP GET to minimize scope changes. Do not claim raw GPS never appears in infrastructure logs (reverse proxies/edge logs). Application code does NOT log raw coordinates, no analytics raw coordinates, no DB persistence, no localStorage/cookie persistence, no GPS in shareable URLs, and API response does NOT echo user coordinates.
56. **Nearby ranking contract:** Locked ranking formula: `distanceRawKm ASC, featured DESC, review_count DESC NULLS LAST, rating DESC NULLS LAST, id ASC`. Radius is a hard filter; venues > 5 km are strictly excluded from Nearby. No new weights or scoring.
